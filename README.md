# The Secret Shop Café | Официальный сайт таверны

> Атмосферный веб-проект тематической кофейни-таверны по мотивам **Dota 2** в городе Майкопе.

---

## 📋 Выполнение требований к проекту

1. **Тематика сайта**:
   - «The Secret Shop Café» — игровая кофейня-таверна, оформленная в стилистике Dota 2 и темного фэнтези. Шрифты Cinzel и Roboto, благородное золото (`#e5c158`), рубиновый акцент (`#ff4c4c`) и мана (`#38bdf8`).
2. **Обязательные элементы**:
   - **Шапка (Header)**: Логотип со щитом, навигация по страницам (`Главная`, `Меню`, `О Лавке`, `Контакты`), кнопка быстрого перехода к свитку заказа / корзине с бейджем, адаптивное мобильное бургер-меню.
   - **Подвал (Footer)**: Описание лавки, навигационные ссылки, режим спавна рун (часы работы), контакты, социальные сети и копирайт.
   - **Меню**: Страница гримуара меню (`menu.html`) с фильтрацией по категориям (Зелья, Десерты, Сытные блюда).
3. **Раздел Контакты с фрагментом карты и адресом**:
   - Адрес: **г. Майкоп, ул. Димитрова, д. 20** (Республика Адыгея).
   - Интерактивный фрагмент карты с маркером на Майкоп, ул. Димитрова, 20.
   - Прямые ссылки для построения маршрута в **Яндекс.Картах** и **2ГИС**, а также подробный гайд «Как добраться» (на авто, общественным транспортом, пешком).
4. **Галерея, форма регистрации/заказа, кнопки соцсетей**:
   - **Галерея**: 6 фотокарточек атмосферы таверны с оверлеем и интерактивным полноэкранным просмотром (Lightbox).
   - **Форма регистрации/заказа**: Полноценная форма бронирования столиков и предзаказа артефактов с валидацией, выбором локации, состава пати и интерактивным окном подтверждения.
   - **Кнопки соцсетей**: Активные кликабельные ссылки со стилизованным ховером на **Telegram, ВКонтакте, Discord, Steam, YouTube**.
5. **Разнообразие блоков**:
   - **Преимущества** (авторская рецептура, 4K трансляции турниров, бонусы за MMR, топовый сетап 240Hz).
   - **Декоративные фэнтези-разделители** с золотыми рунами и щитами.
   - **Этапы (Гайд для новобранцев)**: 4 пошаговых этапа от выбора артефакта до победы в катке.
   - **Команда магов**: Основатель Леонид Якубов, Шеф-миксолог Invoker, Мастер обжарки Lina, Технолог сиропов Alchemist с анимированными аватарами.
6. **HTML / Zero-блок для кастомизации (собственные скрипты и кастомные элементы)**:
   - **Алхимическая лаборатория (Zero-блок кастомизации)**: интерактивный конструктор собственного зелья со сменяемым цветом SVG-колбы, живым расчетом стоимости в золоте, генерацией названия и баффа, и добавлением в заказ.
   - **Живой таймер спавна рун (Live Rune Timer)**: реальный отсчет времени до спавна Bounty Rune (каждые 3 мин) и Wisdom Rune (каждые 7 мин).
   - **Кастомные модальные окна** с составом, лором и игровыми баффами для ВСЕХ позиций меню с закрытием по клику на фон или клавише Escape.
7. **Готовность к публикации (Публикация)**:
   - Все ссылки, стили и изображения настроены с чистыми относительными путями без внешних зависимостей от локальной файловой системы.

## 🚀 Инструкция по публикации сайта (Пункт 7)

### Вариант 1. Публикация на GitHub Pages (Рекомендуется для репозитория `Secretshop.github.io`):
1. Создайте репозиторий на GitHub с именем `Secretshop.github.io` (или вашим никнеймом, например `<username>.github.io`).
2. Загрузите все файлы проекта (`index.html`, `menu.html`, `about.html`, `contacts.html`, `style.css`, картинки) в главную ветку (`main`).
3. Перейдите в **Settings** репозитория &rarr; вкладка **Pages**.
4. В разделе **Build and deployment** выберите Source: **Deploy from a branch**, Branch: **main**, Folder: `/ (root)` и нажмите **Save**.
5. Через 1-2 минуты сайт станет доступен по адресу: `https://<ваш-логин>.github.io/`

### Вариант 2. Публикация через Netlify Drop:
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку проекта `secretshop` прямо в окно браузера.
3. Сайт опубликуется мгновенно и получит публичную ссылку вида `https://secret-shop.netlify.app`.

## 📁 Структура проекта

- `index.html` — Главная страница таверны (Hero, Преимущества, Этапы, Превью меню, Галерея с лайтбоксом, Карта Майкоп Димитрова 20, Форма брони, Соцсети).
- `menu.html` — Гримуар меню (Фильтрация, карточки всех блюд с модалками, Zero-блок «Алхимическая лаборатория», корзина предзаказа).
- `about.html` — О Лавке (Основатель, Команда магов с анимацией, Кодекс лавки, Контакты и Карта).
- `contacts.html` — Выделенный раздел Контактов и Навигации (Подробная карта, схема проезда, форма обратной связи, часы работы).
- `style.css` — Единая адаптивная таблица стилей с анимациями, переменными, кастомным скроллбаром и адаптивностью под мобильные устройства.
